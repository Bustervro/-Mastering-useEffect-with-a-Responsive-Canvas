# Responsive Card App

This project is a React app that uses the useEffect hook to track the browser window size.

The app shows the current window width and height. It also changes the card style when the screen changes between mobile and desktop size.

## Features

- Tracks window width and height in real time
- Uses useEffect
- Adds a resize event listener
- Removes the event listener with a cleanup function
- Changes layout and color for mobile and desktop screens
